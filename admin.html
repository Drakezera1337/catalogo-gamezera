Entrar no painel

Para salvar as alterações no catálogo, o painel precisa de um token do GitHub deste projeto. Criar o token (já vem preenchido). Escolha a validade "No expiration", clique em Generate token e cole aqui.

A posição (1º, 2º…) é a ordem "Mais vendidos" do catálogo. Use ↑ ↓ para mudar.
